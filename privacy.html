Privacy Policy

Applies to GDT-AJ (email-triage), a personal tool used only by its developer on the developer's own Google account. Last updated: 14 November 2026.

Data accessed

With the developer's consent the tool uses these Gmail API scopes: gmail.readonly (read messages) and gmail.compose (create drafts). The same Google Cloud project also declares gmail.modify for other personal scripts of the developer that act only on the developer's own mailbox.

How data is used

  • Message headers and text are read to assign each message a category (for example newsletter, invoice, enquiry).
  • For some enquiries a draft reply is created in Gmail. The tool does not send email; a human reviews and sends every message.
  • For classification and drafting, selected message text, after automated removal of personal identifiers, is sent to a language-model API (Anthropic). Messages that concern legal matters are not sent to the model at all.
  • Locally the tool stores only statistics: a hash of the message id, the category, timing and the sender's domain. It does not store message content.

Sharing and retention

Data is not sold, not used for advertising, and not shared with anyone other than the model API provider described above, solely to perform the functions listed. No person other than the account owner reads the data. Local statistics can be deleted at any time by deleting the metrics file.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and contact

Access can be revoked at any time at myaccount.google.com/permissions. Questions: open an issue in this repository.
